Not seeing other participants?

Try these debugging options:

  • Mobile: Double-tap anywhere to refresh
  • Desktop: Press Ctrl+Shift+R
  • Console Quick Fixes:
    • videoCallDebug.fixStreams() - Fix video streams
    • videoCallDebug.refreshParticipants() - Refresh connections
    • videoCallDebug.hardReset() - Force reconnect all
    • videoCallDebug.logState() - Show debug info
Common Issues:
• Reload page → only see yourself → try fixStreams()
• Empty video tiles → try refreshParticipants()
• Connection stuck → try hardReset()
